# プラットフォーム経営診断ダッシュボード

## 概要
プラットフォームオーナーが登録企業の経営状態を診断するためのダッシュボード。

## 現在のステータス
**🔴 開発保留中** - モックデータで実装済み、実データ連携は未着手

---

## 機能一覧

| 機能 | 説明 | 実装状況 |
|---|---|---|
| ドリルダウン | 企業→支店の展開 | ✅ 完了 |
| ファネル分析 | 問合せ→見学→体験→利用開始 | ✅ モックのみ |
| 二重プログレスバー | 在籍率・出席率の可視化 | ✅ 完了 |
| スパークライン | 売上推移グラフ | ✅ 完了 |
| リスクアラート | 人員欠如・算定ダウン警告 | ✅ 完了 |

---

## ファイル構成

```
src/features/admin/
├── PlatformDashboard.jsx      # 統合版ダッシュボード（経営診断含む）
└── BusinessDiagnosticsDashboard.jsx  # 単独版（別ルート用）
```

## アクセス方法
- URL: `/platform`
- 権限: `platform_owner`, `platform_staff`

---

## 3つのシナリオ企業（モックデータ）

| 企業タイプ | 在籍率 | 出席率 | リスク |
|---|---|---|---|
| 見かけ倒し型 | 100% | 60% | 算定ダウン警告 |
| 配置リスク型 | 87% | 91% | 人員欠如警告 |
| 優良経営型 | 92% | 95% | なし |
