Manecto

操作マニュアル

就労支援事業所のための業務基幹システム。
問い合わせから、日々の記録、月次の請求、就職後の定着支援、そして年次の報酬算定まで。 事業所の業務を一本の線でつなぎます。

2026年8月版  |  https://manecto.web.app

1はじめに

この説明書の考え方と、Manectoの3つの入口について説明します。

1.1 この説明書は「手順書」ではありません

Manectoは「やっていないことが、ひとりでに目に入る」ことを目的に作られています。 未入力のサービス記録、予約が入っていない利用者、入金が確認できていない請求、 連絡が止まったままの問い合わせ——やり残しは、探しにいかなくても画面に数字と色で出てきます。

ですからこの説明書は、ボタンをどの順に押すかではなく、 「いつ・どの画面を開き・何を判断するか」を中心に書いています。 画面の中の細かい操作は、開いてみれば分かるようになっています。 迷ったら、まず開いてみてください。

1.2 3つの入口

Manectoは、使う人によって入口が3つに分かれています。

画面使う人端末入口
スタッフ画面 支援員・サービス管理責任者・支店長 PC https://manecto.web.app
管理画面 経営者・支店長 PC スタッフ画面の左メニュー最下部「会社管理／支店管理」から
利用者ポータル 利用者ご本人 タブレット・スマホ https://manecto.web.app/portal

スタッフ画面と管理画面はGoogleアカウントでログインします。 利用者ポータルは4桁のPINコードだけで入れるので、利用者にメールアドレスやアカウントは必要ありません。 玄関に置いたタブレット1台を全員で共有する使い方を想定しています。

1.3 動作環境

  • PC：Google Chrome または Microsoft Edge の最新版を推奨します
  • タブレット・スマホ：iPad（Safari）、Android（Chrome）
  • インストールは不要です。URLを開くだけで使えます
  • データはクラウドに保存され、複数の端末で同時に開いても自動で同期されます
この説明書での言葉づかい

「利用者」＝サービスを利用するご本人。「スタッフ」＝事業所の職員。 Manectoの画面上でもこの2つを使い分けています。

2ログインと権限

ログインの方法と、役職によって画面がどう変わるかを説明します。

2.1 ログインする

  1. ブラウザで https://manecto.web.app を開く よく使う場合はブックマークに入れておいてください。
  2. 「Googleでログイン」を押す 事業所で使っているGoogleアカウントを選びます。
  3. ダッシュボードが開けば完了 次回からは自動でログインされます。
事前登録が必要です

管理画面のユーザー管理に登録されていないアカウントはログインできません。 新しいスタッフが入ったら、まず管理者が登録してください（10章）。

2.2 自分の権限を確認する

画面の左上、Manectoのロゴの右にあるバッジが、いまログインしている人の権限です。 権限によって、左メニューに出る項目と、見えるデータの範囲が変わります。

バッジ表示役割主にできること

Fleet StaffManecto社員導入支援・システム管理
Captain利用企業の代表自社すべて。管理画面・経理を含む
Chief Officer支店長自支店すべて。月次処理・年次処理・支店管理
Crew現場スタッフ利用者対応・記録・出欠など日常業務
Accountant / Tax Advisor経理担当・顧問税理士経理関連の画面のみ

2.3 メニューは事業所の種別でも変わります

支店に設定されたサービス種別（就労移行支援／就労継続支援B型）によって、 表示されるメニューが切り替わります。 たとえば「月次処理（移行）」は、就労移行支援を行う支店にだけ表示されます。

メニューが出ないときは

権限の問題か、支店のサービス種別が未設定かのどちらかです。 管理画面 → 支店 → サービス種別を確認してください。

4.1 記録は一本の線でつながっています

Manectoでいちばん大事な考え方です。

毎日のチェックインと出欠は、月末の出欠確認表とサービス提供記録になります。 それがそのまま利用料と更生訓練費の請求根拠になります。 就職と定着支援の記録は、翌年度の基本報酬算定区分——つまり単価そのものを決めます。

別々の作業に見えるものが、実は一本でつながっています。 逆にいえば、日々の記録を後回しにすると、そのツケは月末ではなく一年後の報酬に出ます。

5毎日やること

出勤してから退勤までの流れに沿って説明します。

5.1 朝：ダッシュボードを開く

ログインすると最初に出る画面です。2つのものが並んでいます。

  • 活動フィード：事業所全体で、今日誰が何を記録したかがリアルタイムに流れます。 朝いちばんに眺めれば、昨日から今朝にかけて何があったかが分かります。
  • デイリークエスト：その日にやる定型業務のチェックリストです。 終わったものにチェックを入れると完了になります。項目は事業所ごとに設定できます。

5.2 アラート一覧を確認する

期限や予定が近づいている案件が集まる画面です。「明日」と表示されているものは翌日の予定なので、 その日のうちに準備しておきます。

アラートの種類内容
見学予定 / 体験開始来訪・体験開始の予定日が近づいている
定着1〜6ヶ月面談就職後の定着支援面談の時期
受給者証期限受給者証の有効期限が近い。更新手続きが必要
アセスメント提出期限アセスメントの提出期限

利用者名での検索と、種類での絞り込みができます。

5.3 利用者の出欠

本人が入力する（利用者ポータル）

  1. 来所したらタブレットで4桁のPINを入力 本人の画面が開きます。
  2. チェックイン 体温・気分・睡眠・服薬を入力します。この記録が毎日たまっていきます。
  3. 帰るときにチェックアウト その日の振り返りを入力してもらいます。

スタッフが入力・修正する

支援作業 → 日次チェックインから、本人が押し忘れた分の代理入力や、 出退所時刻の修正ができます。当日中に直しておけば、月末の帳票はそのまま出せます。

チェックインの記録は本人に返せます

毎朝の体温・気分・睡眠・服薬は、支援作業 → 月間サマリーで1ヶ月分のグラフになります。 印刷して面談で本人に見せると、体調の波が自分で分かる資料になります。

5.4 活動記録を残す

面談・電話・ご家族対応・その日の出来事など、後から「言った・言わない」になりやすいことを残す場所です。

入口は左メニュー下部の検索窓です。利用者名を打って候補から選ぶと、その人の活動記録が開きます。 書いた内容はダッシュボードの活動フィードにも流れ、事業所全体で共有されます。

なぜ活動記録が重要か

担当が代わったとき、休んだとき、退職したとき——事業所に残るのはこの記録だけです。 「その利用者に何があったか」を思い出せるかどうかが、支援の質と、退所の防止に直結します。

5.5 サービス記録を入力する

支援作業 → サービス記録。提供したサービスの公式な記録で、請求と監査の根拠になります。 通所か在宅かの区別と、支援内容を記録します。

一覧は月単位で表示され、未入力の日は色で分かるようになっています。 毎日入れるのが理想ですが、週末や月末にまとめて追いかけることもできます。

5.6 追客リストで連絡する

問い合わせから利用開始までのフォローは、この画面だけ見ていれば回ります。 今日連絡すべき人だけが出ます。

  1. リストを開く 表示されている人が、今日の対象です。
  2. 電話・メールをして、結果を記録する つながった／つながらなかったを含めて記録します。
  3. 次回の連絡日は自動で入ります 連絡の回数が増えるほど、次の間隔が自動的に空いていきます。自分で予定を管理する必要はありません。

リストが空になっていれば、その日の追客は終わりです。

画面内容
振り返りログ利用者がチェックアウト時に書いた振り返りの一覧
LINE管理LINE公式アカウントに届いたメッセージを利用者に紐付けます。紐付けると過去のやり取りがまとめて活動記録に入ります

6新しい利用者を受け入れる

問い合わせから利用開始までの流れと、契約時に必ず設定するものを説明します。

6.1 まず登録する

CRMボード → 新規利用者を追加。問い合わせを受けた段階で登録してかまいません。 むしろ早く登録するほど追客リストが働きます。名前と連絡先だけでも先に入れてください。

6.2 新規獲得ボードで進める

CRMボードの「新規」タブは、4つの列に分かれています。

新規問合せ  →  面談・見学  →  体験利用  →  契約準備中

状況が進んだら、カードにあるボタンで次の段階へ進めます。 このとき日付の入力を求める確認画面が出ます。ここで入れた日付が、アラートや実績の集計に使われます。

残念ながら利用に至らなかった場合は、カードから終了の操作をします。 このとき理由（見学前離脱／見学後辞退／体験中辞退／契約直前辞退 など）を選びます。 この理由の蓄積が、どこで人が離れているかを見るデータになります。

右上には今月の総問い合わせ数が出ています。

6.3 利用が決まったら設定するもの

ここがあとの月次処理でつまずかないための要です。 契約時に、利用者詳細ページで次を設定してください。

  • 月次利用上限（上限月額） — 未設定だと利用料請求書の対象になりません
  • PINコード（4桁） — 利用者ポータルのログインに使います
  • 受給者証の情報と有効期限 — 期限が近づくとアラートに出ます
  • 更生訓練費の請求事業所 — 自事業所で請求するか、他事業所が請求するか
  • 交通費の設定 — なし／都度（1日あたりの金額）／定期（月額）
  • 送迎の有無 — サービス記録と請求に反映されます
ここを飛ばすと月末に困ります

上限月額が空だと請求書に出てこず、交通費の設定が空だと更生訓練費の金額が合いません。 月末に「なぜこの人が出ないのか」と探すことになるので、契約時にまとめて入れてしまうのが確実です。

6.4 アセスメントと個別支援計画

利用者詳細からアセスメントを開くと、項目に沿って順に入力できます。 入力した内容はそのまま印刷でき、個別支援計画を作るときの資料になります。

この段階で印刷できるもの：フェイスシート／アセスメントシート（一般・精神）／利用者情報

7毎月やること

月初にやることは2つです。「翌月の予定を組む」と「前月を締める」。

7.1 翌月の予定を組む

  1. 支援作業 → スケジュール作成 誰がいつ来るかを組みます。まだ予約が入っていない利用者は、支援作業ダッシュボードに 「未予約 ◯名」と数字で出ているので、そこがゼロになるまで埋めます。
  2. 支援作業 → 月間出席計画 カレンダー形式で月全体を見ながら調整します。偏りや空きが一目で分かります。

7.2 前月を締める

左メニューの月次処理（移行）を開き、まず画面上部で対象月を選びます。 以降の作業はすべて、選んだ月に対して行われます。

月次の締めチェックリスト

  • サービス記録の未入力を埋める（支援作業 → サービス記録で色の付いた日を確認）
  • 出欠確認表を印刷する — 利用者別の出欠一覧
  • サービス提供記録（実績記録票）を一括印刷する
  • 利用料請求書を発行し、一括印刷する
  • 更生訓練費支給申請書を作成し、福祉センターへ提出する
  • 前月分の入金消し込みを確認する

利用料請求書

月次処理の画面で「請求書発行」を押すと、上限月額が設定されている利用者に対して請求が作られます。 対象人数はカードに表示されているので、想定より少なければ設定漏れを疑ってください。 発行後、「一括印刷」でまとめて印刷できます。

更生訓練費

対象の事業所にだけ表示されます。出席実績から自動で計算され、 市の様式どおりの「更生訓練費支給申請書」ができあがります。毎月、福祉センターへ提出する帳票です。

項目計算
訓練費月15日以上の利用 → 3,150円 ／ 14日以下 → 1,600円
交通費通所日数 × 1日単価（在宅日は除く）。定期の場合は月額固定
自治体ごとの様式に対応します

現在は広島市の様式に対応しています。他の自治体の様式も追加できますので、導入担当者にご相談ください。

7.3 入金の消し込みと領収書

支援作業 → 利用料管理（月次処理の「消し込み画面へ」からも入れます）。 発行済みの請求に対して、入金を記録していきます。

未入金はリストに残り続けます。放置されている請求が自然に目に入るので、 別途Excelで管理台帳をつける必要はありません。入金を確認したら、その場で領収書を発行できます。

7.4 月間サマリーを渡す

支援作業 → 月間サマリー。その月のチェックイン記録（体温・気分・睡眠・服薬）がグラフになります。 印刷して面談で本人に渡すと、そのまま支援の材料になります。

スクリーンショット差し込み位置図4：月次処理の画面と各帳票カード

8就職と定着支援

就職後の記録は、翌年の報酬単価に直結します。

  1. 就職が決まったら、CRMボードでステータスを「就職卒業」にする 就職日を入力します。
  2. 定着支援のフェーズに入る 1ヶ月目から6ヶ月目まで段階が分かれ、面談時期になるとアラートに出ます。
  3. 毎月、定着支援レポートを記録する 利用者詳細から開きます。訪問記録・目標・状況を残します。
  4. 定着支援計画も同じ画面から印刷できる
定着支援は書類仕事ではありません

ここで積んだ記録が、翌年度の就労定着率になり、 基本報酬算定区分——つまり事業所の単価そのものを決めます。 年次処理はこの記録を集計しているだけなので、月々の入力が結果のすべてです。

9年に一度やること

左メニュー「年次処理（移行）」から。支店長以上が対象です。

やること内容
平均利用者数算定 前年度の平均利用者数を算定し、職員配置基準を満たしているかを確認します。算定シートとして印刷できます
基本報酬算定区分 届出書（別紙38） 就労定着率から区分を算定し、提出様式を自動で作成します

どちらも、日々のチェックイン・出席実績・定着支援レポートから自動で計算されます。 Excelに転記して集計し直す作業はありません。

この機能は実際に行政へ提出された実績があります

2026年、この機能で算定した書類を実際に行政へ提出し、翌年の就職者数の見込みまで算出しています。

10管理者の設定

左メニュー最下部の「会社管理／支店管理」から入ります。

メニュー内容
企業・支店事業所の基本情報と、サービス種別（就労移行支援／B型）の設定。ここでスタッフ側のメニューの出方が変わります
ユーザー管理スタッフの追加・権限の変更・退職処理。新しいスタッフはここに登録しないとログインできません
権限（RBAC）権限 × 機能のマトリクスで、どの役職に何を許可するかを細かく設定できます
クエストカテゴリデイリークエストの項目とポイントを設定します
職員勤務予定表常勤換算・人員配置基準の確認に使います
申請書類チェックリスト新規指定申請に必要な書類の管理
対象自治体マスター更生訓練費の様式を使う自治体の設定（支援作業 → 設定）

新しいスタッフが入ったら

  1. ユーザー管理 → 追加で、氏名とGoogleアカウントのメールアドレスを登録
  2. 権限を選ぶ（通常のスタッフは Crew）
  3. 所属支店を設定する — 見えるデータの範囲がこれで決まります
  4. 本人にURLを伝える — 登録したGoogleアカウントでログインできます

12困ったときは

症状原因と対処
ログインできない（アカウントがないと出る） 管理画面のユーザー管理に、そのGoogleアカウントのメールアドレスが登録されているか確認してください
左メニューに「月次処理」が出ない 支店のサービス種別に「就労移行支援」が設定されていません。管理画面 → 支店 で確認してください
利用料請求書に特定の利用者が出てこない その利用者の月次利用上限（上限月額）が未設定です。利用者詳細で設定してください
更生訓練費の金額が合わない 交通費の設定（都度／定期・1日単価）と、在宅利用日の記録を確認してください。在宅日は交通費の対象外です
更生訓練費のメニューが出ない 対象の事業所にのみ表示されます。導入時の設定が必要なので導入担当者にご連絡ください
利用者ポータルにログインできない PINコードが未設定か、桁数が違います。利用者詳細の基本情報で4桁のPINを確認してください
印刷すると2ページに分かれてしまう 印刷ダイアログの拡大縮小が変更されている可能性があります。「既定」に戻してください
更新したのに画面が変わらない ブラウザのキャッシュです。Ctrl + Shift + R で再読み込みしてください
別のスタッフが入れた記録が見えない 所属支店が違うと見えません。権限と所属を管理者に確認してください

13用語集

用語意味
CRMボード利用者を状況別に並べた一覧画面。問い合わせから定着完了まで、全員がここに乗ります
追客問い合わせから利用開始までのフォロー連絡
デイリークエストその日の定型業務のチェックリスト。完了するとポイントが貯まります
活動記録利用者ごとの出来事のログ。面談・電話・家族対応など
サービス記録提供したサービスの公式な記録。請求と監査の根拠になります
月次利用上限（上限月額）利用者ごとの自己負担の上限額。利用料請求の計算に使います
更生訓練費自治体から利用者に支給される訓練費・交通費。事業所が毎月まとめて福祉センターに請求します
別紙38基本報酬算定区分の届出様式。就労定着率によって事業所の単価が決まります
サービス種別就労移行支援／就労継続支援B型の区分。支店ごとに設定し、メニューの出方が変わります
