# Manecto 操作マニュアル

就労支援事業所のための業務基幹システム

最終更新: 2026年8月 / 本番URL: https://manecto.web.app

---

## この説明書の読み方

Manectoは「やっていないことが一目で分かる」ことを目的に作られています。
未入力のサービス記録、未予約の利用者、未入金の利用料、止まっている問い合わせ——
やり残しは画面上に**数字と色**で出てくるので、手順を暗記する必要はありません。

そのためこの説明書は、**ボタンの押し方ではなく「いつ・どの画面で・何をするか」**だけを書いています。
画面の中の細かい操作は、開いてみれば分かるようになっています。

---

## 1. Manectoの3つの入口

| 画面 | 使う人 | 端末 | 入口 |
|---|---|---|---|
| **スタッフ画面** | 支援員・支店長 | PC | https://manecto.web.app |
| **管理画面** | 経営者・支店長 | PC | 左メニュー最下部の「会社管理 / 支店管理」 |
| **利用者ポータル** | 利用者本人 | タブレット・スマホ | https://manecto.web.app/portal |

- スタッフ画面・管理画面は**Googleアカウント**でログインします。事前に管理画面でユーザー登録されていないとログインできません。
- 利用者ポータルは**4桁のPINコード**だけ。利用者にGoogleアカウントは不要です。

## 2. 権限（ロール）

ログインした人のロールによって、左メニューに出る項目と見えるデータの範囲が変わります。
画面右上のバッジが自分のロールです。

| バッジ | 役割 | 見える範囲 |
|---|---|---|
| **Grand Admiral** | Manecto運営（開発元） | 全企業 |
| **Fleet Staff** | Manecto社員 | 全企業（システム管理） |
| **Captain** | 利用企業の代表 | 自社すべて（管理画面・経理を含む） |
| **Chief Officer** | 支店長 | 自支店すべて（月次・年次処理を含む） |
| **Crew** | 現場スタッフ | 日常業務（利用者・記録・出欠） |
| **Accountant / Tax Advisor** | 経理担当・顧問税理士 | 経理関連のみ |

> **支店のサービス種別**（就労移行支援 / B型）によっても、メニューの出方が変わります。
> 「月次処理（移行）」が出ない場合は、管理画面 → 支店 → サービス種別の設定を確認してください。

## 3. 業務の全体像

```
【入口】問い合わせが来る
   └→ CRMボード に登録
        ↓  追客リスト が「そろそろ電話する人」を出す
   見学 → 体験
        ↓
【利用開始】契約・受給者証
   └→ アセスメント → 個別支援計画
        ↓
【毎日】出欠と記録
   ├→ 利用者ポータル でチェックイン／チェックアウト
   ├→ サービス記録（支援内容）
   └→ 活動記録（面談・電話・出来事）
        ↓
【毎月】月次処理
   ├→ 翌月の予定を組む（スケジュール作成 → 月間出席計画）
   └→ 前月を締める（出欠確認表・サービス提供記録・利用料請求・更生訓練費）
        ↓
【就職】定着支援（最長3年6ヶ月）
   └→ 定着支援レポートを毎月記録
        ↓
【毎年】年次処理
   ├→ 平均利用者数の算定（人員配置基準）
   └→ 基本報酬算定区分の届出（別紙38）
```

**この流れは一本につながっています。**
日々のチェックインとサービス記録が、月次の請求根拠になり、
就職と定着支援の記録が、年次の**基本報酬算定率**——つまり売上の根拠そのものになります。
「記録を後回しにする」ことのコストが、一年後に効いてくる構造です。

## 4. 毎日やること

### 4.1 朝：ダッシュボードを開く

ログインすると最初に出る画面です。

- **活動フィード** — 事業所全体で今日誰が何を記録したかがリアルタイムで流れます
- **デイリークエスト** — その日にやる定型業務のチェックリスト。完了するとポイントが入ります

### 4.2 アラート一覧

「明日、見学・体験・追客の予定がある人」が出ます。前日のうちに準備・確認するための画面です。

### 4.3 利用者の出欠

| 誰が | どこで | 何を |
|---|---|---|
| 利用者本人 | 利用者ポータル（タブレット） | 来所時に**チェックイン**（体温・気分・睡眠・服薬）／帰る時に**チェックアウト**（振り返り） |
| スタッフ | 支援作業 → 日次チェックイン | 本人が押し忘れた分の代理入力・時間の修正 |

> 毎朝のチェックイン内容は蓄積され、**月間サマリー**でグラフになります。体調の波を本人に見せる資料として使えます。

### 4.4 記録を残す

- **活動記録** — 左メニュー下部の検索窓に利用者名を打ち、選ぶとその人の活動記録に飛びます。面談・電話・家族対応など「言った・言わない」になりがちな出来事はここへ。
- **サービス記録** — 支援作業 → サービス記録。通所／在宅の別と支援内容を記録します。**未入力の日は一覧で色が付く**ので、月末にまとめて追いかけられます。
- **振り返りログ** — 利用者がチェックアウト時に書いた振り返りの一覧です。

### 4.5 追客（問い合わせのフォロー）

**追客リスト**には「今日連絡すべき人」だけが出ます。

電話・メールを記録すると、**次回連絡日が自動で入ります**（連絡回数が増えるほど間隔が空く設計）。
自分でスケジュールを管理する必要はありません。リストが空になっていれば、その日の追客は終わりです。

> LINE公式アカウントに来たメッセージは、支援作業 → LINE管理 で利用者に紐付けられます。
> 紐付けると過去のやり取りがまとめて活動記録に入ります。

## 5. 新しい利用者を受け入れる

1. **CRMボード**に登録する（問い合わせ段階でOK）
2. ステータスをカードのドラッグで動かす：`問い合わせ → 見学 → 体験 → 利用中`
3. 利用開始が決まったら、利用者詳細から個人情報を埋める
4. **アセスメント**を実施 → そのまま印刷して個別支援計画の資料にできます

印刷できるもの：フェイスシート／アセスメントシート（一般・精神）／利用者情報

> 利用者ごとの**上限月額**（負担上限額）は利用者詳細で設定します。ここが空だと利用料請求書が作られません。

---

## 6. 毎月やること（月次処理）

### 6.1 月のはじめ：翌月の予定を組む

1. **支援作業 → スケジュール作成** — 誰がいつ来るかを組みます。未予約の利用者は支援作業ダッシュボードに「未予約◯名」と出ます
2. **支援作業 → 月間出席計画** — カレンダー形式で月全体の予定を確認・調整します

### 6.2 月の頭：前月を締める（左メニュー「月次処理（移行）」）

対象月を選ぶと、その月に対して次の作業ができます。

| やること | 内容 |
|---|---|
| **出欠確認表** | 利用者別の出欠一覧を一括印刷 |
| **サービス提供記録** | 実績記録票を一括印刷（利用者・自治体提出用） |
| **利用料請求書** | 上限月額が設定された利用者に対して請求書を発行 → 一括印刷 |
| **更生訓練費** | 福祉センターへ請求する「更生訓練費支給申請書」を、出席実績から市の様式どおりに自動作成（対象事業所のみ表示） |

### 6.3 入金の消し込み

**支援作業 → 利用料管理**（または月次処理の「消し込み画面へ」）

発行済みの請求に対して入金を記録します。**未入金は一覧で残り続ける**ので、放置されている請求がひと目で分かります。入金確認後、領収書を発行できます。

### 6.4 月間サマリー

**支援作業 → 月間サマリー** — チェックインの体温・気分・睡眠・服薬をグラフ化したもの。印刷して本人に渡せます。

## 7. 就職と定着支援

1. 就職が決まったらCRMボードでステータスを **就職済み** に
2. 以後、定着支援のフェーズに入ります（最長3年6ヶ月）
3. 利用者詳細 → **定着支援レポート** を月ごとに記録します
4. **定着支援計画**も同じ画面から印刷できます

> ここで積んだ記録が、翌年度の**基本報酬算定区分**（定着率）の根拠になります。
> 定着支援は「書類仕事」ではなく、**翌年の報酬単価を決める作業**です。

---

## 8. 年に一度やること（年次処理）

左メニュー「年次処理（移行）」から。支店長以上が対象です。

| やること | 内容 |
|---|---|
| **平均利用者数算定** | 前年度の平均利用者数を算定し、職員配置基準を満たしているか確認 |
| **基本報酬算定区分 届出書（別紙38）** | 就労定着率から区分を算定し、提出様式を自動生成 |

日々のチェックイン・出席実績・定着支援レポートから自動で計算されます。
**別途Excelで集計し直す必要はありません。**

## 9. 管理者の設定（管理画面）

左メニュー最下部から入ります。

| メニュー | 内容 |
|---|---|
| **企業・支店** | 事業所情報、サービス種別（移行／B型）の設定。ここでメニューの出方が変わります |
| **ユーザー管理** | スタッフの追加・ロール変更・退職処理 |
| **権限（RBAC）** | ロール × 機能のマトリクスで、どのロールに何を許すかを編集 |
| **クエストカテゴリ** | デイリークエストの項目とポイントを設定 |
| **職員勤務予定表** | 常勤換算・配置基準の確認に使う勤務予定表 |
| **申請書類チェックリスト** | 新規指定申請に必要な書類の管理 |

## 11. 困ったときは

| 症状 | 対処 |
|---|---|
| ログインできない（アカウントがないと出る） | 管理画面のユーザー管理に、そのGoogleアカウントのメールアドレスが登録されているか確認 |
| 左メニューに「月次処理」が出ない | 支店のサービス種別に「就労移行支援」が設定されていない。管理画面 → 支店 で確認 |
| 利用料請求書に特定の利用者が出てこない | その利用者の**上限月額**が未設定。利用者詳細で設定してください |
| 更生訓練費のメニューが出ない | 対象自治体の事業所にのみ表示されます。導入時の設定が必要です |
| 利用者ポータルにログインできない | 4桁PINが未設定または誤り。利用者詳細でPINを確認してください |
| 更新したのに画面が変わらない | ブラウザキャッシュ。`Ctrl + Shift + R` で再読み込み |

## 12. 用語

| 用語 | 意味 |
|---|---|
| **CRMボード** | 利用者をステータス別のレーンで並べたカンバン。問い合わせから完了まで全員がここに乗る |
| **追客** | 問い合わせ〜利用開始までのフォロー連絡 |
| **クエスト** | 日々の定型業務のチェックリスト。完了でポイントが貯まる |
| **活動記録** | 利用者ごとの出来事ログ（面談・電話・家族対応など） |
| **サービス記録** | 提供したサービスの公式な記録。請求・監査の根拠になる |
| **更生訓練費** | 自治体から利用者に支給される訓練費・交通費。事業所が毎月まとめて福祉センターに請求する |
| **別紙38** | 基本報酬算定区分の届出様式。就労定着率で単価が決まる |
