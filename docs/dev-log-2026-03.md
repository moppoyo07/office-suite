### 年次処理センター 追加

**コミット:** `aee8f02`

#### 概要
期末に必要な届出書・算定シートを一か所から操作できる「年次処理センター」を新設。

#### 追加ファイル

##### `src/pages/AnnualReportCenterPage.jsx`
- ルート: `/annual`
- 支店長・プラットフォームオーナーのみ表示（左メニューに「年次処理 (移行)」追加）
- カード形式で届出書・算定シートへナビゲート
  - 平均利用者数算定シート（`/admin/average-users-sheet`）
  - 基本報酬算定区分 届出書・別紙38（`/annual/basic-reward`）
  - 就労定着者の状況（準備中）

##### `src/pages/BasicRewardReportPage.jsx`
- ルート: `/annual/basic-reward`
- 就労移行支援に係る基本報酬の算定区分に関する届出書（**別紙38**）
- Firestoreの `clients`（status=completed）から就職後6ヶ月定着者を自動集計
- 前年度・前々年度の月別定着者数 → 就労定着率 → 区分（1〜8）を自動算定
- 印刷プレビュー表示 + 別紙38フォーマットでのポップアップ印刷
- `useTenant` の `currentTenant.branch` から `capacity`（定員）・`designationDate`（指定日）を取得
  - ※ 旧実装の `useWorkplaceInfo`（`workplaces/main_office` ハードコード）は廃止

### 平均利用者数算定シート A4印刷 改善

`window.print()` だったものを `window.open` によるポップアップ印刷に切り替え。

**帳票フォーマット（A4縦）**
1. タイトル：「平均利用者数算定シート（○○年度）」
2. 副題：「（生活介護・共同生活援助・就労定着支援・自立生活援助を除く）」
3. メインテーブル：No. / 受給者番号 / 氏名 / 月別利用延べ日数（4〜3月）/ 日数計
4. 計行（月別合計）
5. 開所日数行（月別）
6. 前年度平均利用者数（右下）

- `colgroup` + HTML属性 + inline style のみ使用（MUI sx 使わず）
- `@page { size: A4 portrait; margin: 8mm; }`
